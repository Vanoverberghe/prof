Cadre

Une bibliothèque municipale utilise une base de données pour gérer ses collections, ses adhérents et les emprunts de livres. La bibliothécaire souhaite améliorer son service en automatisant les rappels de retour par SMS.

Objectif

La durée maximale d'emprunt d'un livre est de 14 jours. Passé ce délai, les adhérents n'ayant pas rendu leur livre reçoivent des rappels par SMS. La bibliothécaire dispose d'une plateforme d'envoi de SMS, mais il est nécessaire de préparer les données et les messages à envoyer.

Pour cela, on devra extraire depuis la base de données la liste des emprunts en retard (livres non rendus, empruntés depuis plus de 14 jours), puis contacter chaque adhérent par SMS sur son téléphone portable.

Rappels techniques

Le système de gestion de base de données utilisé est SQLite, accessible via le module sqlite3 de la bibliothèque standard Python.

Connexion et exécution de requêtes :

DB_PATH = "biblio.sqlite"
conn = sqlite3.connect(DB_PATH)
cursor = conn.cursor()

resultats = cursor.execute(
    "SELECT id, titre FROM livre ORDER BY titre LIMIT 5"
)
# resultats est itérable, chaque élément est un tuple
for r in resultats:
    print("id:", r[0], ", titre:", r[1])

Passage de paramètre dans une requête SQL :

resultat = cursor.execute(
    """SELECT titre FROM livre
    WHERE genre = ? ORDER BY titre""",
    ("policier",)
)

Les clauses SQL à utiliser sont : SELECT, FROM, JOIN, ON, WHERE, IS NULL, ORDER BY

Rappel sur les dates : les dates sont stockées au format AAAAMMJJ (ex. : 20251101 pour le 1er novembre 2025). Ce format permet de comparer des dates directement avec les opérateurs <, >, = dans SQL et en Python.

Numéros de téléphone

La plateforme d'envoi de SMS requiert un numéro de téléphone au format 06XXXXXXXX ou 07XXXXXXXX — 10 chiffres au total, sans espace, ni point, ni autre caractère. Malheureusement, les téléphones ont été enregistrés sans distinction entre mobiles et fixes, et avec des formats variés : "(0)6 12 34 56 78", "07.89.01.23.45", "0623145896 dupuis"…

Rappel : on peut utiliser la méthode isdigit() de la classe str pour déterminer si un caractère est un chiffre.

>>> '3'.isdigit()
True
>>> 'A'.isdigit()
False

Détermination de la liste des emprunts en retard

Pour pouvoir envoyer les rappels, la bibliothécaire doit d'abord identifier les adhérents concernés à partir de la base de données.

On commencera par extraire tous les emprunts en retard via la fonction emprunts_en_retard(date), puis on déterminera pour chaque adhérent son emprunt le plus récent (le livre qu'il a pris en dernier, qui est donc celui dont le retour est le plus urgent).

Interrogation de la base de données

La fonction emprunts_en_retard(date) doit récupérer tous les emprunts de livres non rendus dont la date d'emprunt est strictement antérieure à la date date (format AAAAMMJJ).

On souhaite récupérer les champs suivants :

  • identifiant de l'emprunt (emprunt.id)
  • titre du livre
  • téléphone de l'adhérent
  • date de l'emprunt

Le résultat sera trié par id_adherent puis par date_emprunt croissants.

Détermination de l'emprunt le plus récent par adhérent

Un adhérent peut avoir plusieurs livres en retard simultanément. Pour lui envoyer un seul SMS, on souhaite identifier son emprunt le plus récent (la date d'emprunt la plus grande), qui correspond au livre pris en dernier.

La fonction emprunt_le_plus_recent(emprunts) prend en paramètre une liste d'emprunts sous la forme :

(id_emprunt, titre_livre, tel_adherent, date_emprunt)

Elle doit renvoyer un dictionnaire dont la clef est le numéro de téléphone de l'adhérent, et la valeur associée est le tuple correspondant à son emprunt le plus récent.

Exemple : pour Alice Martin, qui a deux emprunts en retard :

(60, "Fahrenheit 451", "06 12 34 56 78", "20250928"),
(2,  "1984",           "06 12 34 56 78", "20251026"),

Son emprunt le plus récent est 1984 (emprunté le 20251026), donc le dictionnaire doit contenir :

{
  "06 12 34 56 78": (2, "1984", "06 12 34 56 78", "20251026"),
  ...
}
